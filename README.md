# PhysioPeaksFinder
MATLAB GUI for semi-automatic peak detection dedicated to semi-periodic physiological signals

<img width="608" height="538" alt="Picture1" src="https://github.com/user-attachments/assets/2fad6a34-666e-4717-96da-c062a5046322" />

**Installation**
The application can be installed by running PhysioPeaksFinder.mlappinstall. Developed and tested on MATLAB2024a.


**Manual peak detection**
Peak can be added using the wheel-click directly where desired. Right-click is used to remove a peak. Left-click allows to flag a peak.
